# M1 research import — исторические исходные данные

Эти файлы **скопированы** 2026-11-13 из `alfuwerce-art/CubeGame`, ветка `review/m1-creature-family-research` на основе `776a6ce`. Они сохранены как исследовательский контекст **Factoria**, а не как текущая игровая документация.

- `M1_ASSET_ANIMATION_FACTORY_PIPELINE.md`: технология переработки и новых моделей, предложенная для M1.
- `M1_CREATURE_FAMILY_RESEARCH_TASK.md`: исследовательское ТЗ R0.
- `M1_ALPHA_CREATURE_IDENTITY_REGISTRY.csv`: идентичность и локаторы 156 записей.
- `M1_CREATURE_FAMILY_MATRIX.md`: структурные и identity-семейства.
- `M1_R0_CREATURE_FAMILY_RESEARCH_REPORT.md`: выводы/ограничения исследований.
- `extract_creature_identity_registry.py` и `ALPHA_RESEARCH_README.md`: **архивный** исследовательский экстрактор, использует зависимости из основного CubeGame и локальный Alpha-кэш, **не** является standalone инструментом Factoria.

В исходных файлах имеются относительные Markdown-ссылки, которые в новом каталоге могут не разрешаться. Оригинальные сведения и статусы не изменяли, чтобы сохранить provenance. Для актуальной работы используйте самостоятельные документы Factoria `AGENTS.md`, `01...`, `02...`, `03...` после их публикации DeepSeek.

**Важно:** данные Alpha и локальные конвертированные ресурсы не дают права публиковать игровые 3D-ассеты. Нельзя считать `LOCAL_ONLY` подтверждением наличия моделей в сборке Unity Player.
