## Лицензионный блокер (главное)

Civitai API для этой версии возвращает:

```text
allowCommercialUse = RentCivit
allowDerivatives   = False
allowNoCredit      = False
```

Это означает:
- **коммерческое использование сгенерированных изображений автором явно не разрешено**
  (`RentCivit` — разрешение на аренду модели через генератор Civitai, а не на коммерческие
  изображения у пользователя);
- **запрещены производные** — нельзя обучать на её выходах собственную LoRA/модель
  (это важно: планируемая `Factoria Style LoRA` не может обучаться на картинках этой LoRA);
- требуется указание автора (`allowNoCredit = False`).

Фактически это значит: LoRA годится как **экспериментальный инструмент для сравнения стиля**,
но **не может быть объявлена производственной** для коммерческой игры без письменного
разрешения автора.

## Решение

1. LoRA устанавливается и подключается (эксперимент разрешён владельцем).
2. В workflow и отчётах фиксируется статус **EXPERIMENTAL / LICENSE_BLOCKED_FOR_PRODUCTION**.
3. **Fictiverse Voxel XL остаётся основной** LoRA (openrail, коммерческое использование
   допускается с use-based restrictions); Civitai-вариант не заменяет её.
4. Производственные пути без этого риска:
   - SDXL IPAdapter + собственный утверждённый референс (`DREAMSHAPER_XL_REFERENCE_LOCK.json`);
   - собственная `Factoria Style LoRA`, обученная **только** на собственных/лицензированных
     изображениях владельца;
   - письменное разрешение автора (внешнее действие владельца, не задача исполнителя).

## Последствия

- Сравнительные тесты рас (орк/человек/эльф) выполняются на этой LoRA как на референсе стиля —
  результаты нельзя переносить в релиз без смены модели стиля.
- В `DREAMSHAPER_XL_CIVITAI_VOXEL*.json` предупреждение о лицензии встроено в MarkdownNote,
  чтобы его нельзя было «не заметить».
