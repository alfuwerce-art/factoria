# COMFY-STYLE-02 — Установка и настройка ComfyUI под Factoria VOXEL_STYLE

**Проект:** Factoria · **Репозиторий:** `alfuwerce-art/factoria` · **Ветка:** `factory/work`
**Рабочая папка:** `D:\Projects\CubeGame Factory` · **Статус:** AUTHORIZED (2026-11-13)
**Основание:** FACT-D19. Документ восстановлен по утверждённому тексту ТЗ сессии 2026-11-13
(ранее файл отсутствовал в репозитории).

## Цель

Подготовить **существующий** portable ComfyUI к фиксации voxel-стиля: custom nodes,
базовый checkpoint, два режима запуска, лимиты ресурсов. Художественная генерация Orc
на этом этапе не выполняется.

## 1. Проверить существующий ComfyUI (не ставить второй)

Зафиксировать: путь, версию, embedded Python, Torch, CUDA, custom nodes, модели,
свободное место. Не менять: глобальный Python, PATH, CUDA, NVIDIA driver, CubeGame, Unity.

## 2. Минимальный стек custom nodes

| Нода | Назначение | Условие |
|---|---|---|
| ComfyUI-Manager | управление нодами | без дубликата, если уже есть |
| ComfyUI-Crystools | мониторинг RAM/VRAM/CPU/GPU/времени | обязательно |
| ComfyUI_IPAdapter_plus | style reference | проверить совместимость с текущей версией ComfyUI |
| comfyui-controlnet-aux | canny/lineart/pose/depth препроцессинг | на будущее |
| rgthree-comfy | организация workflow | обязательно |

## 3. Базовый checkpoint

Только `Stable Diffusion 1.5 fp16 ema-only` (`v1-5-pruned-emaonly-fp16.safetensors`).
До скачивания: официальный источник, лицензия, размер, SHA-256. После — сверить hash.
Не ставить SDXL/FLUX/Qwen/несколько checkpoint/пачки LoRA.

## 4. IPAdapter и ControlNet weights

Ноды ставим сейчас, **веса не скачиваем** автоматически. Сначала определить точные
файлы, источник, размер, лицензию, ожидаемую память и выдать списком в отчёте.
Никаких гигабайт «на всякий случай».

## 5. Два режима запуска (воспроизводимые launcher/config)

- `SAFE_BASELINE` — `--novram` (минимум VRAM);
- `CPU_FALLBACK` — `--cpu` (генерация полностью вне GPU, если `--novram` превышает лимит).

## 6. Жёсткие лимиты ресурсов

RAM ≤ 15 GB · дополнительная VRAM ≤ 2 GB относительно baseline до запуска.
Пригодность не определяется размером checkpoint — пики измеряются на реальном прогоне.

## 7. Критерии приёмки

1. `CHECKPOINT` определяется ComfyUI (виден в списке нод `CheckpointLoaderSimple`), SHA-256 совпал.
2. Оба launcher'а реально стартуют сервер и отдают UI.
3. Ни одна custom node не падает на импорте при старте.
4. Crystools отдаёт мониторинг (backend-роуты + панель в UI).
5. Отчёт содержит все поля из шаблона ТЗ (пути, версии, хэши, лимиты, блокеры).

## Вне рамок

Второй ComfyUI, глобальные изменения окружения, скачивание тяжёлых весов без согласования,
три десятка расширений, художественная генерация Orc и замер пиков — это шаг владельца.
