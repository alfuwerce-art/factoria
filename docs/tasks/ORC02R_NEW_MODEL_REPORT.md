## 1. Одна команда

```powershell
python scripts\orc02r\run_orc02r.py `
  --reference measurements\orc_reference.json `
  --profile scripts\orc02r\profiles\orc.json `
  --out outputs\prototypes\orc_02r\run1
```

Стадии: reference (числа) → generate (NEW geometry) → determinism → profile variation → Blender headless
(валидация + `.blend` + экспортный `.glb` + 3 вида) → `report.json`. Ручных кликов нет.

прирост VRAM **0 МБ** (Cycles CPU).

## 3. Пропорции (воксели × 0.0268 м)

| Плоскость | Значение | Доля роста |
|---|---|---|
| пол → макушка (без хохолка) | 69 вокселей = **1.849 м** | 100 % |
| голова (подбородок → макушка) | 24 вокселя = 0.64 м | **34.8 %** |
| торс (пояс → плечо) | 19 вокселей = 0.51 м | 27 % |
| ноги (пол → пах) | 20 вокселей = 0.54 м | 29 % |
| ширина плеч по рукам | 36 вокселей = 0.96 м | 52 % |

Рост совпадает с измерением старого Orc: **+0.06 %** (1.849 против 1.848 м). Масштаб сетки 0.0268 м
подобран так, чтобы сохранить рост при увеличенной голове.

### Стыки

Зазор — «канавка»: на стыке снимается наружная оболочка, сердечник остаётся. Фактические зазоры
по Z: плечо→предплечье 0, бедро→голень 0, голень→стопа 0, таз→торс 0, торс→голова 0
(сегменты стыкуются, шов читается канавкой), предплечье→кисть **1 воксель**. Пересечений модулей — **0**.
