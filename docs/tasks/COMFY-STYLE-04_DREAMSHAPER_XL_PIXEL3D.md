## 1. Цель

Подготовить существующую установку ComfyUI к генерации стилизованных 3D-персонажей в
едином визуальном стиле **Pixel-Textured 3D** на модели **DreamShaper XL**.

Дальнейший путь: ComfyUI → Tripo → Blender → LEGO-модули → Rig → Animation → Unity.
Нужны игровые персонажи с полноценной узнаваемой анатомией, угловатой геометрией и
пиксельными текстурами — не реалистичные люди, не плоские пиксельные рисунки и не
примитивные кубические фигуры.

## 2. Текущая среда (зафиксировать фактически)

ComfyUI `D:\programs\ComfyUI` 0.45.0 · RTX 4060 Laptop 8 GB · RAM 32 GB · python 3.13.14 embedded ·
torch 2.14.1+cu130 · Manager, Crystools, IPAdapter Plus, ControlNet Aux, rgthree установлены ·
SD 1.5 сохранить как резервный. Вторая установка ComfyUI, изменения глобальных Python/CUDA/PATH
и поломка существующих workflow запрещены.

## 3. DreamShaper XL

Найти официальный источник и совместимый checkpoint, проверить происхождение/формат/лицензию/
коммерческое применение, скачать FP16, положить в существующий `models/checkpoints`,
сверить SHA-256, убедиться что модель видна в `CheckpointLoaderSimple`, проверить загрузку
через текущий torch/CUDA. Старый checkpoint не удалять.
Если лицензия/коммерческое использование неясны — зафиксировать блокер и не объявлять модель
пригодной к производству.

## 4. Pixel-Textured 3D

Найти специализированную SDXL LoRA/стилевой модуль с приоритетом: Pixel-Textured 3D,
Stylized 3D Game Characters, pixel-art textures on 3D geometry, blocky/angular fantasy characters.
Не путать с обычным 2D pixel art. До скачивания проверить совместимость с SDXL, лицензию,
размер, зависимости, примеры реального использования, применимость к игровым персонажам.
Нельзя ставить случайную LoRA только из-за слова `pixel` в названии.
Если подходящей LoRA нет — альтернатива через SDXL IPAdapter + референсы; экспериментальный
промпт не выдавать за подтверждённый style lock.

## 5. IPAdapter и ControlNet

Подготовить SDXL-совместимые веса и workflow: IPAdapter — удержание единого стиля по
референсам; ControlNet — силуэт, поза, композиция. Проверить совместимость весов/нод/
препроцессоров с DreamShaper XL. Не скачивать лишнего; если вес слишком велик для 8 GB —
указать проблему и более экономную альтернативу.

## 6. Workflow

- `DREAMSHAPER_XL_BASE.json` — без стилевых модулей;
- `DREAMSHAPER_XL_PIXEL_STYLE.json` — с выбранным стилевым модулем;
- `DREAMSHAPER_XL_REFERENCE_LOCK.json` — стиль через IPAdapter и референс;
- `DREAMSHAPER_XL_POSE_CONTROL.json` — контроль позы через ControlNet.

Все совместимы с текущей ComfyUI. Если референса нет — workflow готов к подключению, но
работоспособность не подтверждается фиктивно. Отсутствие весов/входных изображений не должно
приводить к незаметному запуску неправильной ветки графа.

## 7. Ограничения VRAM

RTX 4060 Laptop 8188 MiB. Безопасные настройки для 768×768, 768×1024, 1024×1024 (если хватит),
batch = 1. Проверить режимы управления VRAM, не совмещать несовместимые аргументы запуска.
Особо проверить существующий `--novram --reserve-vram 5` на пригодность для SDXL; при
необходимости — отдельный launcher. Не объявлять режим оптимальным без измерений.

## 8. Техническая проверка

Целостность файлов, загрузка checkpoint, регистрация LoRA и нод, корректность workflow,
отсутствие ошибок импорта, совместимость зависимостей, сохранность прежних workflow и SD 1.5.
Технический прогон выполнения допускается для подтверждения загрузки и связности графа.
Художественную оценку и утверждение эталонного персонажа **не выполнять**.
