# Human — редактор Cube World Alpha

Источник — оригинальная сборка Alpha, указанная в [общем аудите](ALPHA_CHARACTER_EDITOR_CATALOG.md).
Номер в UI начинается с 1, индекс в сейве с 0. Описания отражают видимые воксели проекций. Названия видов Haircut являются интерпретацией формы.

### Hair color, глаза и другие поля

Hair color показывает общую сетку 16×7. Сохранённый RGB умножает вершинные цвета всего Haircut, включая видимые воксели бороды и усов в соответствующих вариантах. На Face цвет не переносится. Рисунок или цвет глаз меняется с выбором Face.
Class включает Warrior, Ranger, Mage, Rogue. Класс влияет на стартовое оружие и игровые способности. Диапазоны Face/Haircut и модель базового тела сохраняются при смене класса. Name хранится отдельно как текстовое поле создания персонажа.
