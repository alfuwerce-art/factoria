# COMFY-STYLE-11 — Human Base Body, первый FRONT smoke

**READY_FOR_OWNER_VISUAL_REVIEW · 14 ноября 2026**

Два запроса завершились успешно в отдельном локальном ComfyUI. Каждый дал один RGB PNG 768×1024. Выполнены только Human Male FRONT и Human Female FRONT, по одному запросу на пол.

## Шаблон и направляющие

[BASE_BODY_V1](../../workflows/character_factory/base_body/BASE_BODY_V1.json) задаёт цельную серую техническую болванку, пустую голову, горизонтальные руки и раздельные стопы. В ветке Base Body [компилятора](../../scripts/comfyui/compile_character_factory.py) для prompt оставлено описание корпуса из профиля. Данные кожи, деталей головы и текстурного оформления используются в маршрутах модулей, где они нужны. Скомпилированные Face и Haircut для проверочного входа совпали с графами предыдущего компилятора.

Две собственные направляющие строятся [скриптом](../../scripts/comfyui/prepare_human_base_front_guides.py). У них общий холст 768×1024, ось X=384, нейтральный фон RGB 158, одна линия плеч и одинаковые пределы по макушке и подошвам. Ширина головы 252 px и высота 144 px заданы как ориентир по оболочке 14×8 вокселей. Габариты корпуса — проектные. Мужская направляющая немного шире в плечах и талии, женская чуть шире в тазу. На обеих есть плоские кисти, цельные стопы и пустая плоскость лица. Направляющая каждого пола подана и в Canny, и как anchor plate для img2img.

Измерение использует крупнейшую связную область с яркостью минимум на 16 ниже медианы верхнего фона. У обоих кадров тёмная кромка идёт по контуру, глубина с фронта выражена слабо. В зоне таза тень может читаться как край отдельной детали, особенно у Female. Визуальная приёмка и пригодность для будущего 3D остаются открытыми.

## Артефакты и воспроизведение

PNG, исходные направляющие и сравнительный лист сохранены локально в `outputs/factory/human_base_front_v1/`. На GitHub опубликованы параметры и хэши, точные API-графы, отчёт и скрипт построения направляющих. [Ограничение FACT-D21](../decisions/FACT-D21-civitai-voxel-lora-license.md) для результатов с ral-vxl сохраняется.

Команда сборки обоих API-графов для проверки. Она использует Python ComfyUI с Pillow и пишет JSON без отправки в очередь. Для побайтового соответствия отправленным графам префикс SaveImage записан в опубликованных API.

```powershell
& $comfyPython -B scripts/comfyui/prepare_human_base_front_guides.py --out $comfyInput
foreach ($sex in 'MALE', 'FEMALE') {
    $pack = Join-Path $comfyInput "HUMAN_${sex}_BASE_FRONT_PACK.json"
    & $comfyPython -B scripts/comfyui/compile_character_factory.py --asset BASE_BODY --race HUMAN --gender $sex --view FRONT --base-img2img --reference-pack $pack --input-dir $comfyInput --out $compiled
}
```
