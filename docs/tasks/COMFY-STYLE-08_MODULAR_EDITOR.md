# COMFY-STYLE-08 — заменяемые части редактора CubeGame

**CUBEGAME_CONTRACT / PROPOSAL** · дизайн для ревью владельца.

## Слоты

| Слот | Якорь и ресурс CubeGame | Свидетельство Alpha |
|---|---|---|
| Head | череп по `head`, определяет семейство сокетов; для Skeleton вариант Skull | Face подставляет целый head .cub |
| Face | face preset на `face`, брови, нос, рот и стык челюсти, материал/маски лица; опциональная Jaw на `jaw` | детали и RGB встроены в голову |
| Eyes | парные `eye.L/R`, отдельная геометрия радужки/зрачка, отдельная палитра или emission | в Face игрока видимые RGB-воксели; у Skeleton 0x11 отдельный overlay глаз |
| Hair | `hairline`, asset ID и hair RGB; можно очищать по правилам расы | отдельный Haircut overlay, общий hair RGB |
| Beard | `chin` и `jaw`, отдельный asset ID, beard RGB с опциональной связью с hair | детали под лицом в overlay, отдельный UI не подтверждён |
| Ears | `ear.L/R`, парный модуль, симметричный либо асимметричный вариант | уши относятся к контуру головы |
| Horns | `horn.L/R`, отдельный модуль с ограничением по форме головы | отдельный creator control не подтверждён |
| Crest | `crown`, независимо от рогов, допускает конфликт с Hair/головным убором | Lizard имеет Haircut overlay |
| Torso | `spine` и `pelvis`, грудной и тазовый base mesh, материалы отдельно | отдельный body .cub |
| Arms | `upper_arm.L/R` и `forearm.L/R` | отдельные выбираемые ресурсы плеча и предплечья не установлены |
| Hands | `hand.L/R`, отдельные кисти, хват как метаданные | отдельный .cub кисти, используемый по сторонам |
| Legs | `thigh.L/R` и `shin.L/R` | независимых опций в editor нет |
| Feet | `foot.L/R`, материал обуви или кости | отдельный foot .cub |
| Tail | `tail.root`, опциональная цепочка костей и независимый меш | у редакторских Lizard пустой Tail, у Dragon 0x65 есть модель |
| Equipment | `head`, `back`, `shoulder.L/R`, `grip.L/R` и существующие игровые attach roles; визуальный слой скрытия | другие модели экипировки и class starter set через игровой путь |
| ParticleEffects | сокеты `eye.L/R` и `torso` с отдельным effect ID и каналом эмиссии, если разрешено профилем расы | данные референса Fildor / Enderman; selectable эффект в Alpha UNKNOWN |

## Сборка и замены

Каталог запчастей хранит стабильный `partId`, имя слота, разрешённые `raceId`/body presets, `rigArchetype` и его версию, необходимые сокеты, `headFamily` для модулей лица, набор материальных каналов и маски скрытия для экипировки. Левую и правую части пары валидировать и заменять как одну транзакцию. Обозначать допустимое отсутствие модуля явно. Head сменяет семейство сокетов и повторно проверяет Face/Eyes/Hair/Beard/Ears/Horns/Crest. При несовместимости показать конфликт и выбор разрешённой замены до применения.

Разрешить материальные instance-override для кожи, волос, глаз, бороды, чешуи, ткани и эмиссии по карточке расы. Совместимый вариант цвета меняет материал. Поворот и положение глаза определяет сокет. При смене Hair и Beard пересобираются их ресурсы, а значения Eyes и Face сохраняются. Скрытие шлемом временно исключает отрисовку перекрытых частей, выбранные ID сохраняются. Правила пересечения ушей с Hair, Horns/Crest с Equipment и Beard с Torso проверять в нейтральной стойке и при анимации. Если экспорт объединяет поверхности, сохранить редактируемые источники и симметрию ID при обратном импорте.

Схема `race_recipe.json` описывает лабораторный рецепт. Игровое сохранение CubeGame требует отдельного утверждения и миграционной проверки. Для проверки на следующем разрешённом этапе собрать один Humanoid Avatar и набор сокетов, проверить bind pose, idle/walk/attack, сцепление экипировки, смену одной детали с сохранением остальных ID, hide/unhide экипировки, round-trip каталога и повторную загрузку. У Dragonkin проверить хвост отдельно от Humanoid Avatar, у OrcFemale учитывать частичный собственный actor Alpha. Исходные PNG задают дизайн фронта. Риг, веса, mesh seams и анимация требуют 3D-артефактов и собственных проверок.
