# PIPELINE_GAPS — чего не хватает готовому стеку

**Обновлено:** 2026-11-13 (PREP-00)
**Назначение:** точный список того, что готовые инструменты **не** делают, и какую функцию придётся реализовать позже. Не план разработки, а фиксация разрыва между «инструмент есть» и «конвейер работает».

---

## 1. Блокеры, подтверждённые аудитом

| # | Разрыв | Чем подтверждено | Минимальное закрытие |
|---|---|---|---|
| G1 | **Нет Blender** — нет геометрии, armature, skinning, анимации, CLI-экспорта | рекурсивный поиск `blender.exe` (C:\, D:\ до глубины 4) → 0; нет в PATH/реестре | PREP-01: официальный Blender 5.2.4 LTS zip на D: |
| G2 | **ComfyUI не найден**, хотя ТЗ считает его имеющимся | нет каталога `*omfy*`, ярлыков, записи в реестре; порт 8188 не слушается | получить фактический путь у пользователя; установку не дублировать |
| G3 | **Нет авториггинг-инструмента** (UniRig/MeshRig и др.) | не установлено, не исследовано | PREP-04: кандидаты + лицензия + 8 ГБ VRAM |
| G4 | **Нет инструмента новых движений** (Cascadeur/AI motion) | не установлено | PREP-05: сначала лицензия Cascadeur (риск ограничения экспорта FBX) |
| G5 | **Нет системного Node.js** | нет в PATH | n8n невозможен без Node.js → аргумент против n8n на текущем этапе |

## 2. Функциональные разрывы готового стека (не блокеры, но важно)

| # | Готовый инструмент | Чего он **не** делает | Что придётся написать/настроить позже |
|---|---|---|---|
| F1 | Rigify | не классифицирует анатомию и не находит суставы произвольной модели; не гарантирует экспортную совместимость | `Rig Fitter` (подгонка согласованного skeleton к landmarks и пропорциям) — **отложено по ТЗ** |
| F2 | Blender Automatic Weights | ломает крупные плечи, таз, доспехи, хвосты, необычные тела | правила skinning (rigid vs deform), коррекция весов по семействам |
| F3 | Blender FBX-экспорт | не гарантирует корректность осей/единиц/bind pose/animation для Unity | валидатор экспорта + контракт `CG_*` skeleton (осей, имён, sockets) |
| F4 | Unity Mecanim | не «понимает» нечеловекоидные анатомии без Generic-пути и IK-слоёв | retarget/IK-конфигурация под каждый archetype |
| F5 | ComfyUI (если найдётся) | image-to-3D ≠ контролируемая переработка существующего 3D-меша; даёт черновик с артефактами | отдельный маршрут 3D-to-3D redesign, очистка топологии |
| F6 | AI motion | не даёт финальные боевые клипы с таймингами и контактами | ручная доработка + привязка к gameplay events |
| F7 | — | нет оркестратора партий (статусы, ретраи, регрессии) | Python runner; n8n только при доказанной пользе |

## 3. Ограничения среды, влияющие на конвейер

| Ограничение | Следствие |
|---|---|
| 8 ГБ VRAM (фактически ~6.7 ГБ свободно) | только одна тяжёлая AI-модель за раз; кандидатов оценивать документально до скачивания |
| C: свободно 68.2 ГБ | все веса/кэши — на D: |
| Windows PowerShell 5.1 (нет pwsh 7) | `Tee-Object` пишет UTF-16 → перекодировать в UTF-8; в скриптах избегать `python3` |
| Git identity не настроена | commit невозможен до локальной настройки |
| Нет remote Factory-репозитория | `PUSH=NOT_CONFIGURED`; работа локальная |
| Unity на этом этапе запрещён для проверки | экспорт в Unity остаётся `NOT_TESTED`, пока пользователь не разрешит отдельную тестовую среду |
