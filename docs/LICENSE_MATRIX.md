## 3. Что важно для CubeGame (правовые ограничения)

1. **Blender не делает модели GPL.** Скрипты, которые являются производными Blender API и распространяются, — отдельный вопрос; созданные `.blend`/`.fbx`/текстуры принадлежат автору. Это ключевой факт для коммерческих ассетов.
2. **Alpha-ассеты CubeGame публиковать нельзя** и нельзя считать их основой коммерческого меша (ТЗ §1.6, AGENTS §4). Лицензия на них у лаборатории отсутствует.
3. **AI-веса ≠ свободные.** Многие image-to-3D/motion веса имеют некоммерческие условия или ограничения на выход. Проверять до скачивания, фиксировать в этом файле.
4. **Cascadeur** — главный риск по экспорту: бесплатный тариф может ограничивать экспорт FBX. Проверить до установки, иначе PREP-05 упрётся в платный тариф (запрещено без согласования).
5. **n8n** — не OSI-лицензия; для внутреннего использования ок, но ставить только при доказанной пользе.
6. **WinRAR** — только для распаковки на этой машине; в производственном конвейере не использовать (заменить на `Expand-Archive`).

- [ ] Точная лицензия и её версия с официального сайта/репозитория (сохранить URL и дату).
- [ ] Разрешено ли коммерческое использование **выходных** ассетов.
- [ ] Есть ли ограничения на использование весов/обучающих данных.
- [ ] Требуется ли аккаунт, телеметрия, онлайн-активация.
- [ ] Размер загрузки и место на диске (C: свободно 68 ГБ, D: 642 ГБ).
- [ ] Совместимость с 8 ГБ VRAM.
